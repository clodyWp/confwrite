# 技术文档图表 - 数据流图（DFD）

## 视觉表现形式

- **核心元素**：
  - 圆形/圆角矩形 = 过程（数据处理）
  - 矩形 = 外部实体（数据源/目的地）
  - 双线矩形 = 数据存储（数据库/文件）
  - 箭头 = 数据流（标注数据内容）
- **分层**：
  - Level 0（上下文图）— 系统与外部的数据交互
  - Level 1（详细过程）— 系统内部的数据处理
  - Level 2（更细粒度）— 子过程的详细数据流

## 典型结构

```
                    ┌──────────┐
         ┌─────────│  订单数据  │◀─────────┐
         │         └──────────┘           │
         │              │                 │
  ┌──────▼──┐    ┌─────▼─────┐    ┌──────┴──┐
  │  客户    │───▶│ 处理订单   │───▶│  仓库    │
  └─────────┘    └───────────┘    └─────────┘
```

## 使用场景

| 场景 | 目的 |
|------|------|
| 系统设计 | 展示数据在系统中的流转路径 |
| 数据治理 | 梳理数据的来源和去向 |
| 安全审计 | 追踪敏感数据的流动 |
| 运维文档 | 展示数据备份/同步链路 |
| 故障复盘 | 展示异常数据的传播路径 |

## 适用文档类型

系统设计文档、数据治理文档、安全审计文档、故障复盘报告

## 推荐工具

| 工具 | 适用情况 |
|------|---------|
| draw.io | 有 DFD 专用模板 |
| PlantUML | 通用绘图 |
| Mermaid `graph` | 简单场景可用 |

## 绘图要点

1. 数据流箭头必须标注数据内容（如"订单信息"、"用户凭证"）
2. 外部实体用名词（客户、供应商），不用动词
3. 过程用动词+名词（处理订单、验证身份）
4. 数据存储用双线矩形，标注存储类型
5. 分层绘制：先画 Level 0 全景，再展开 Level 1 细节
