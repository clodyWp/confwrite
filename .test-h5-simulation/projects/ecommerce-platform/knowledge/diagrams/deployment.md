## 视觉表现形式

- **核心元素**：3D 图标或方块（服务器/容器/服务）+ 网络连接线
- **分层/分区域**：用虚线框划分环境（生产环境、测试环境）
- **可标注**：IP 地址、端口号、实例数、配置规格
- **网络元素**：防火墙、负载均衡、CDN、DNS 等
- **颜色区分**：不同环境用不同颜色（绿色=生产、黄色=预发、灰色=测试）

## 使用场景

| 场景 | 目的 |
|------|------|
| 运维手册 | 展示线上环境的部署拓扑 |
| 架构设计 | 展示服务的物理/逻辑部署方案 |
| 灾备方案 | 展示多机房/多活部署结构 |
| 新人入职 | 了解开发/测试/生产环境的差异 |
| 故障复盘 | 标注故障影响范围 |

## 适用文档类型

运维手册、部署文档、灾备方案、故障复盘报告

| 工具 | 适用情况 |

## 绘图要点

1. 区分逻辑部署（服务怎么分布）和物理部署（机器在哪）
2. 标注关键配置：实例数、端口、规格
3. 多环境分开画（开发/测试/生产）
4. 标注网络边界（VPC、安全组、防火墙）
5. 保持与架构图的一致性（服务名、分层要对应）
