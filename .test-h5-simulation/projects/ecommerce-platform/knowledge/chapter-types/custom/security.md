# 安全章写作指南

## 内容要求
- 必须包含安全需求分析
- 必须包含安全架构设计
- 必须包含认证授权方案
- 必须包含数据加密方案
- 必须包含安全审计方案
- 必须包含安全事件响应

## 写作风格
使用"功能描述型"写作风格：
1. 按安全层次组织
2. 每个安全措施详细说明
3. 使用威胁模型辅助说明
4. 强调安全合规性

## 与其他章节的关系
- 基于需求章和架构章
- 贯穿所有功能模块
- 为实施章提供安全要求

## 常见错误
- 避免安全措施不完整
- 避免缺少威胁分析
- 避免安全与功能脱节
