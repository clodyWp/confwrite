# 功能需求详细说明

## 1. 入库管理模块

### 1.1 扫码入库（FR-001）

**功能描述**：
仓管员使用 PDA 手持终端扫描物料条码，系统自动识别物料信息并创建入库单。

**业务规则**：
1. 支持一维码（Code 128、EAN-13）和二维码（QR Code、DataMatrix）
2. 扫码后自动解析物料编码、批次号、生产日期
3. 系统校验物料编码是否存在于基础数据中
4. 扫码失败时提示错误原因（条码损坏、物料不存在等）

**输入**：
- 物料条码（一维/二维）
- 供应商送货单号（手动输入）

**输出**：
- 入库单草稿（待确认）
- 物料信息展示（编码、名称、规格、单位）

**异常处理**：
- 条码无法识别：提示重新扫码或手动输入
- 物料不存在：提示联系管理员添加物料
- 重复扫码：提示已存在入库单

### 1.2 入库单生成（FR-002）

**功能描述**：
扫码确认后，系统自动生成正式入库单，记录入库明细。

**入库单字段**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 入库单号 | String | 是 | 系统自动生成，格式：RK+年月日+流水号 |
| 物料编码 | String | 是 | 从条码解析 |
| 物料名称 | String | 是 | 自动带出 |
| 规格型号 | String | 否 | 自动带出 |
| 批次号 | String | 是 | 从条码解析 |
| 入库数量 | Number | 是 | 手动输入 |
| 单位 | String | 是 | 自动带出 |
| 供应商编码 | String | 是 | 手动选择 |
| 供应商名称 | String | 是 | 自动带出 |
| 入库日期 | Date | 是 | 默认当前日期 |
| 库位编码 | String | 是 | 手动选择或系统推荐 |

**业务规则**：
1. 入库单号唯一，不可重复
2. 入库数量必须 > 0
3. 同一入库单可包含多个物料（批量入库）
4. 入库单状态：草稿 → 待质检 → 已质检 → 已入库

### 1.3 质检流程（FR-003）

**功能描述**：
入库物料需经过质检，合格后方可入库，不合格品自动隔离。

**质检流程**：
1. 入库单创建后，状态变为"待质检"
2. 质检员接收质检任务，进行抽检或全检
3. 质检结果录入：合格数量、不合格数量、不合格原因
4. 合格物料：状态变为"已入库"，更新库存
5. 不合格物料：自动生成退货单，库存不增加

**质检记录**：
| 字段 | 说明 |
|------|------|
| 质检单号 | 系统自动生成 |
| 入库单号 | 关联入库单 |
| 质检员 | 操作人员 |
| 质检时间 | 操作时间 |
| 合格数量 | 通过质检的数量 |
| 不合格数量 | 未通过质检的数量 |
| 不合格原因 | 文本描述 |
| 处理方式 | 退货/让步接收/返工 |

## 2. 库存管理模块

### 2.1 实时库存查询（FR-004）

**功能描述**：
支持多维度库存查询，实时展示库存状态。

**查询维度**：
1. **按物料查询**：输入物料编码或名称，查看所有仓库的库存
2. **按仓库查询**：选择仓库，查看该仓库所有物料库存
3. **按批次查询**：输入批次号，查看该批次的库存和流转记录
4. **组合查询**：支持多条件组合（物料+仓库+批次）

**查询结果**：
| 字段 | 说明 |
|------|------|
| 物料编码 | 物料唯一标识 |
| 物料名称 | 物料描述 |
| 仓库编码 | 所在仓库 |
| 库位编码 | 具体库位 |
| 批次号 | 生产批次 |
| 库存数量 | 当前库存 |
| 可用数量 | 可用库存（扣除预留） |
| 预留数量 | 已预留未出库 |
| 最后入库时间 | 最近一次入库 |
| 最后出库时间 | 最近一次出库 |

**业务规则**：
1. 库存数据实时更新（入库/出库后立即刷新）
2. 支持模糊查询（物料名称、编码前缀）
3. 查询结果支持导出 Excel
4. 查询响应时间 < 2 秒

### 2.2 库存预警（FR-005）

**功能描述**：
当库存低于安全库存时，系统自动发送补货提醒。

**预警规则**：
1. **安全库存预警**：库存 ≤ 安全库存时触发
2. **最低库存预警**：库存 ≤ 最低库存时触发（紧急）
3. **超储预警**：库存 ≥ 最大库存时触发（避免积压）

**预警配置**：
| 物料分类 | 安全库存 | 最低库存 | 最大库存 |
|----------|----------|----------|----------|
| A 类物料 | 1000 | 500 | 5000 |
| B 类物料 | 500 | 200 | 2000 |
| C 类物料 | 200 | 100 | 1000 |

**预警通知**：
1. 系统内消息：登录后可见
2. 邮件通知：发送给仓库主管和采购员
3. 短信通知：最低库存预警时发送

**预警处理**：
1. 仓库主管确认预警
2. 生成补货建议单
3. 采购员根据建议单下单
4. 预警状态：未处理 → 处理中 → 已处理

### 2.3 ABC 分类管理（FR-006）

**功能描述**：
根据物料重要程度进行分类管理，不同类别采用不同盘点频率。

**分类标准**：
- **A 类物料**：占库存金额 70%，品种数 20%（高价值）
- **B 类物料**：占库存金额 20%，品种数 30%（中价值）
- **C 类物料**：占库存金额 10%，品种数 50%（低价值）

**盘点策略**：
| 分类 | 盘点频率 | 盘点方式 | 责任人 |
|------|----------|----------|--------|
| A 类 | 每日 | 全量盘点 | 仓库主管 |
| B 类 | 每周 | 抽样盘点（30%） | 仓管员 |
| C 类 | 每月 | 抽样盘点（10%） | 仓管员 |

**盘点流程**：
1. 系统自动生成盘点任务
2. 仓管员使用 PDA 扫码盘点
3. 盘点数据上传系统
4. 系统对比账面库存，生成差异报告
5. 差异处理：盘盈入库、盘亏出库

## 3. 出库管理模块

### 3.1 多类型出库（FR-007）

**功能描述**：
支持多种出库类型，满足不同业务场景。

**出库类型**：
| 类型 | 说明 | 关联单据 |
|------|------|----------|
| 生产出库 | 生产领料 | 生产工单 |
| 销售出库 | 成品发货 | 销售订单 |
| 样品出库 | 样品寄送 | 样品申请单 |
| 调拨出库 | 仓库间调拨 | 调拨单 |
| 报废出库 | 物料报废 | 报废申请单 |

**出库单字段**：
| 字段 | 说明 |
|------|------|
| 出库单号 | 系统自动生成 |
| 出库类型 | 生产/销售/样品/调拨/报废 |
| 物料编码 | 出库物料 |
| 出库数量 | 出库数量 |
| 批次号 | 指定批次或系统推荐 |
| 关联单号 | 工单号/订单号 |
| 出库日期 | 操作日期 |
| 领用人 | 领料人/收货人 |

### 3.2 出库策略（FR-009）

**功能描述**：
支持先进先出（FIFO）和指定批次出库策略。

**FIFO 策略**：
1. 系统自动推荐最早入库的批次
2. 推荐规则：按入库日期升序排列
3. 仓管员按推荐批次拣货
4. 如需修改批次，需主管审批

**指定批次策略**：
1. 领料人指定批次号
2. 系统校验该批次库存是否充足
3. 充足则锁定库存，生成出库单
4. 不足则提示库存不足

**批次锁定**：
1. 出库单创建后，对应批次库存被锁定
2. 锁定库存不可被其他出库单使用
3. 出库完成后，锁定释放，库存扣减
4. 出库单取消，锁定释放，库存恢复
