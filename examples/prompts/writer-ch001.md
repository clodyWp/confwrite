# 示例 Prompt：Writer Subagent

本文件展示 Writer subagent 接收到的完整 prompt 示例。

---

## 实际 Prompt

```markdown
# 写作任务

你需要撰写章节 **ch001** 的内容。

## 素材包

# ch001 素材包：项目背景与目标

## 章节信息
- **章节 ID**: ch001
- **标题**: 项目背景与目标
- **相关分类**: 业务, 技术

## 相关文件
共 2 个相关文件：

- **requirements.md** (业务)
  - 摘要: 本项目旨在构建一个高性能的 Web 应用系统...
- **api-spec.md** (技术)
  - 摘要: 本文档定义了系统的 API 接口规范...

## 关键数据
以下是从资料中提取的关键指标：

- **系统可用性**: 99.99%
- **平均响应时间**: < 100ms
- **最大并发用户数**: 10000

## 技术术语
确保在写作中正确使用以下术语：

RESTful, OAuth2.0, PostgreSQL, Redis, JWT, HTTPS, CRUD

## 需求要点
写作时需要覆盖以下需求：

- 必须支持用户注册和登录
- 需要实现细粒度的权限控制
- 必须支持多租户架构
- 系统可用性: 99.99%
- 平均响应时间: < 100ms

## 写作提示
1. 仔细阅读相关文件，理解上下文
2. 确保使用正确的技术术语
3. 引用关键数据时保持一致性
4. 覆盖所有需求要点
5. 保持与整体文档风格一致

## 写作要求

1. **严格遵循素材包**：使用素材包中提供的文件、数据和术语
2. **数据一致性**：所有数字、指标必须与素材包中的"关键数据"一致
3. **术语准确**：使用素材包中列出的技术术语
4. **覆盖需求**：确保覆盖素材包中提到的所有需求要点
5. **结构清晰**：使用合适的标题层级（##、###、####）
6. **引用来源**：在引用具体数据或概念时，注明来自哪个文件

## 输出格式

将完成的章节内容写入文件：**drafts/chapters/ch001.md**

文件格式：
```markdown
# ch001 项目背景与目标

## 概述
简要介绍本章节内容...

## 主要内容
...

## 小结
总结本章节要点...
```

## 注意事项

- 不要编造素材包中没有的数据
- 如果素材包信息不足，在文末标注"[需要补充: xxx]"
- 保持与整体文档风格一致
- 字数要求：根据章节复杂度，通常 2000-5000 字
```

## 期望输出示例

Writer subagent 应该生成类似以下内容：

```markdown
# ch001 项目背景与目标

## 概述

本章节介绍项目的背景信息和核心目标，为后续的系统设计和技术实现奠定基础。

## 项目背景

随着企业数字化转型的深入，对 Web 应用系统的需求日益增长。本项目旨在构建一个高性能、高可用的企业级 Web 应用系统，满足用户管理和数据处理的核心需求。

### 业务背景

根据需求文档（requirements.md），当前企业面临以下挑战：
- 用户规模快速增长，需要支持 10000 并发用户
- 数据安全要求提高，必须满足等保二级安全要求
- 系统可用性要求严格，需要达到 99.99%

### 技术背景

从技术角度（api-spec.md），系统需要：
- 采用 RESTful API 设计，确保接口的标准化和可扩展性
- 实现 OAuth2.0 认证，保障用户身份安全
- 使用 PostgreSQL 作为主数据库，Redis 作为缓存层

## 项目目标

### 核心目标

1. **用户管理系统**
   - 必须支持用户注册和登录
   - 需要实现细粒度的权限控制
   - 必须支持多租户架构

2. **数据管理系统**
   - 必须支持 CRUD 操作
   - 需要实现数据分页查询
   - 必须支持数据导入导出

### 性能目标

根据需求文档，系统必须达到以下性能指标：
- **系统可用性**: 99.99%
- **平均响应时间**: < 100ms
- **最大并发用户数**: 10000

### 安全目标

- 必须实现 HTTPS 加密传输
- 需要实现审计日志
- 必须满足等保二级安全要求

## 项目范围

本项目包括以下核心模块：
1. 用户管理模块
2. 数据管理模块
3. 权限控制模块
4. 审计日志模块

## 小结

本章节介绍了项目的背景信息和核心目标。系统需要满足高可用性（99.99%）、高性能（< 100ms 响应时间）、高并发（10000 用户）的要求，同时必须保证数据安全和权限控制。

下一章将详细介绍系统的整体架构设计。
```

---

## 关键点

1. **Prompt 结构**：
   - 任务说明
   - 素材包内容（完整嵌入）
   - 写作要求
   - 输出格式
   - 注意事项

2. **素材包内容**：
   - 章节信息
   - 相关文件列表
   - 关键数据（来自基线）
   - 技术术语
   - 需求要点
   - 写作提示

3. **Writer 的职责**：
   - 读取素材包
   - 根据"相关文件"列表，用 `read` 工具读取具体资料
   - 根据素材包中的信息撰写章节
   - 确保数据与基线一致
   - 将结果写入 `drafts/chapters/ch001.md`
