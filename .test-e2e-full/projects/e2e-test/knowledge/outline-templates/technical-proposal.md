# 技术方案模板

## 使用说明

本模板适用于技术项目方案文档，包含以下核心章节：

1. **概述章**：项目背景、目标、范围
2. **需求章**：功能需求、非功能需求
3. **架构章**：系统架构、技术选型
4. **功能章**：详细功能设计
5. **实施章**：实施计划、里程碑
6. **保障章**（可选）：组织保障、技术保障
7. **附录章**（可选）：术语表、参考文献

## 写作建议

- 概述章应简明扼要，控制在5000-8000字
- 需求章应详细列出所有需求，控制在8000-12000字
- 架构章应包含架构图和技术选型理由，控制在10000-15000字
- 功能章是核心章节，应详细描述每个功能，控制在12000-20000字
- 实施章应包含时间表和里程碑，控制在10000-15000字

## 注意事项

- 所有数据必须来自数据基线，不得编造
- 图表占位符格式：`[diagram:id:title]...[/diagram]`
- 保持与大纲一致，不要偏离主题
