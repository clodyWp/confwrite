# 功能章写作指南

## 内容要求
- 必须详细描述每个功能模块
- 必须包含功能流程图
- 必须包含界面设计说明（如适用）
- 必须包含业务规则说明
- 必须包含异常处理说明

## 写作风格
使用"功能描述型"写作风格：
1. 按功能模块组织
2. 每个功能详细描述
3. 使用流程图辅助说明
4. 包含使用示例

## 与其他章节的关系
- 基于需求章和架构章
- 为实施章提供功能规格
- 是文档的核心章节

## 常见错误
- 避免功能描述不完整
- 避免缺少流程图
- 避免与需求不一致

## 示例结构
```
## 功能模块A
### 功能描述
### 业务流程
### 界面设计
### 业务规则
### 异常处理

## 功能模块B
### 功能描述
### 业务流程
### 界面设计
### 业务规则
### 异常处理

## 功能集成说明
```
