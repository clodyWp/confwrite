# 写作风格知识库

本目录包含不同章节类型的写作风格指南。

## 风格类型

| 文件 | 风格 | 适用章节 |
|------|------|----------|
| `overview.md` | 概述型 | 项目背景、总论、简介、需求分析 |
| `functional.md` | 功能描述型 | 功能模块、解决方案、技术架构 |
| `commitment.md` | 承诺型 | 质量保障、售后服务、运维方案 |
| `list.md` | 列表型 | 交付物清单、功能列表 |
| `process.md` | 流程型 | 实施方法论、工作流程 |

## 匹配规则

每个风格文件的 frontmatter 定义匹配规则：

- `tags`: 标题关键词匹配
- `matchCategories`: 素材分类匹配

## 使用方式

`KnowledgeLoader` 根据章节的 `title` 和 `relatedCategories` 自动匹配最合适的风格指南，注入到素材包中。

## 自定义

用户可直接编辑本目录下的 `.md` 文件来调整写作风格，无需修改代码或重新编译。
