## 结构要求

- 使用"总-分-总"或"总-分"结构
- 首段给出核心结论或关键判断
- 先宏观后微观，逐步聚焦到具体问题
- 末尾用一段话承上启下，引出后续章节

## 语言风格

- 客观陈述，避免主观臆断
- 适当引用行业背景、政策依据、数据支撑
- 使用"由此可见"、"综上所述"等逻辑连接词
- 避免"众所周知"、"不言而喻"等空泛表述

## 典型结构模板

```
1. 背景与现状
   - 行业大环境
   - 政策/市场驱动因素

2. 问题与挑战
   - 当前痛点（用数据量化）
   - 不解决的后果

3. 必要性与紧迫性
   - 为什么现在必须做
   - 预期收益

4. 本章小结
   - 核心结论
   - 引出下文
```

## 图表建议

- 适合使用对比表格（现状 vs 目标）
- 可使用趋势图展示变化
- 架构图展示整体关系

## 字数分配建议

- 背景现状：30%
- 问题分析：40%
- 必要性论证：20%
- 小结：10%
