## 视觉表现形式

- **核心元素**：矩形（步骤）+ 菱形（判断/分支）+ 圆角矩形/椭圆（开始/结束）+ 箭头（流向）
- **流向**：从上到下 或 从左到右
- **变体**：
  - 泳道图（Swimlane）— 按角色/系统分列，展示各方职责
  - BPMN 规范 — 复杂业务流程，支持事件、网关、消息等语义

## 典型结构

```
         ┌─────────┐
         │  开 始   │
         └────┬────┘
              ▼
        ┌───────────┐
        │ 接收请求   │
        └─────┬─────┘
              ▼
         ┌─────────┐    否
         │ 参数合法?│──────────┐
         └────┬────┘          │
           是  ▼              ▼
        ┌───────────┐   ┌─────────┐
        │ 处理业务   │   │ 返回错误 │
        └─────┬─────┘   └────┬────┘
              ▼              │
        ┌───────────┐        │
        │ 返回结果   │◄───────┘
        └─────┬─────┘
              ▼
         ┌─────────┐
         │  结 束   │
         └─────────┘
```

## 使用场景

| 场景 | 目的 |
|------|------|
| 需求文档 | 描述业务逻辑的完整路径 |
| 算法说明 | 展示算法的执行路径和分支判断 |
| CI/CD 文档 | 展示构建、测试、部署的自动化流程 |
| 测试文档 | 梳理测试路径和分支覆盖 |
| 运维手册 | 展示故障处理步骤（告警流程图） |

## 适用文档类型

PRD/需求文档、技术方案、测试计划、运维手册

## 推荐工具

| 工具 | 适用情况 |
|------|---------|
| Mermaid `flowchart` | Markdown 内嵌，支持泳道 |
| PlantUML 活动图 | 复杂流程，支持并行/循环 |
| draw.io | 正式文档 |
| Visio / ProcessOn | 企业环境常用 |

## 绘图要点

1. 流程方向统一（不要混用从上到下和从左到右）
2. 判断菱形的分支要标注条件（是/否、通过/拒绝）
3. 泳道图明确各方职责边界
4. 复杂流程拆分为子流程，避免一张图超过 20 个节点
5. 开始和结束节点各只有一个
