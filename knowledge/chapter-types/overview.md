# 概述章写作指南

## 内容要求
- 必须包含项目背景
- 必须包含项目目标
- 必须包含项目范围
- 必须包含文档结构说明

## 写作风格
使用"概述型"写作风格，采用总-分结构：
1. 先给出整体概述
2. 再分点详细说明
3. 最后总结要点

## 与其他章节的关系
- 通常在文档开头
- 为后续章节提供背景和上下文
- 不应包含过多技术细节

## 常见错误
- 避免过于技术化
- 避免遗漏项目目标
- 避免篇幅过长（应控制在8000字以内）

## 示例结构
```
## 项目背景
## 项目目标
## 项目范围
## 文档结构
## 术语定义
```
